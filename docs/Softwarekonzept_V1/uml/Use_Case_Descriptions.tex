\section*{Use Case 01: View Climate Data -- Own Office}

\textbf{Actors:} Employee, Department Manager, Senior Management 

\textbf{Basic Flow:}
\begin{enumerate}
    \item User navigates to the \textit{My Office} view in the webapp
    \item System verifies the user is assigned to an office room
    \item System calculates current room occupancy ... how exactly?
    \item Occupancy $\geq 5$: System fetches current measurements for temperature, humidity and air quality
    \item System displays live current value based on the system defined interval measurements for all three metrics
    \item User selects a time range (day/week/month)
    \item System fetches historical measurements data for the selected range and renders a chart
    \item Configured threshold limits are shown as reference lines in the chart .... and past violations highlighted(?)
    \item If a treshold violation is currently active, a warning banner (?) is shown with tips to mitigate the warning (?)
\end{enumerate}

\textbf{Alternative Flows:}
\begin{itemize}
    \item \textbf{Occupancy $<$ 5:} System does not load any measurement data and displays the message: \textit{"Climate data for this room is currently unavailable due to not meeting minimum occupancy requirement}
    \item \textbf{No data for selected time range:} Display message \dots
    \item \textbf{Sensor station or Raspberry Pi offline:} Display latest known data with an info warning that systems are currently not operational?
\end{itemize}

\textbf{Business Classes:} Room / OfficeRoom (r), Absence (r), ClimateTip(r/c)
